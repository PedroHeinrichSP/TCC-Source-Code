# Scripts do Windows

Use os wrappers `cmd/` para iniciar rapidamente e `powershell/` quando precisar de parametros.

## Scripts principais

- `setup.cmd` / `setup.ps1`
- `benchmark_quick.cmd` / `benchmark_quick.ps1`
- `benchmark_all.cmd` / `benchmark_all.ps1`
- `download_dataset.cmd` / `download_dataset.ps1`
- `generate_report.cmd` / `generate_report.ps1`

## Fluxo sugerido

1. `setup.*`
2. `download_dataset.*`
3. `benchmark_quick.*`
4. `generate_report.*`
