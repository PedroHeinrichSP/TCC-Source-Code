# Scripts do Linux / macOS

Os scripts `*.sh` cobrem setup, benchmark e relatorio.

## Principais

- `setup.sh`
- `setup_local.sh`
- `setup_lego.sh`
- `setup_gs_static.sh`
- `download_dataset.sh`
- `benchmark_quick.sh`
- `benchmark_all.sh`
- `generate_report.sh`

## Uso rapido

```bash
cd scripts/linux
chmod +x *.sh
./setup.sh
./download_dataset.sh
./benchmark_quick.sh
./generate_report.sh
```
